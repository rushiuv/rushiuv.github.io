Wooting 是这条链上**把磁传感做成消费品**的一家公司：每颗键轴下面一颗霍尔器件，测的是键帽沿 Z 轴的直线位移，不是角度。它的价值在于把"磁传感器 + 固件 + 上位机接口"这条链完整暴露给用户——触发点、回差、上报率都是可配置项，位移原始值还能通过开源 SDK 直接读到应用里。

## 2015 年起步，做模拟输入的键盘

官网 about 页的原话是 2015 年开始这段路，目标是把"模拟信号键盘"做成新标准，理由是当时的行业把数字（开/关）键盘当默认选项，把精力花在 RGB 上。团队页列了三十多人，含工程、固件、供应链与社区运营。公司没有在 about 页写注册地与人数规模，本页不补。[关于 Wooting](https://wooting.io/zh-CN/about)

产品线：80HE+（TKL）、60HE v2（60%）、Two HE（全尺寸）、UwU（小键盘）、60HE v2 Module（单独 PCBA 供客制化）。轴体两条腿走路：自研 Lekker / Lekker Tikken 系列（Light、Medium），以及引入第三方的磁轴（TTC 万磁王、Gateron 磁玉等），说明它把"轴"当成可替换件而不是封闭件。

## 位移怎么测、怎么变成触发

官方产品页的技术叙述可以拆成四层，每层都是可核对的公开口径。

| 环节 | 公开口径 | 出处 |
| --- | --- | --- |
| 传感 | 每键霍尔效应（Hall effect），模拟信号；Lekker Tikken 保留完整 4 mm 行程 | 产品页 |
| 位移量化 | 触发点在 0.1~4.0 mm 之间，以 0.1 mm 为单位设定 | 产品页 |
| 触发逻辑 | 按下与释放灵敏度分别可调，可开 Rapid Trigger（连续快速触发），逐键设置 | 产品页 |
| 上报 | 真 8 kHz 回报率，官方算到每键 0.125 ms 的输入延迟 | 产品页 |
| 上位机 | Wootility 配置软件；另有开源 Wooting Analog SDK（Rust，跨平台）把模拟值交给应用 | GitHub |

第三行是磁轴键盘与普通键盘的分水岭：普通机械轴只有一个开关点，磁轴给的是连续位移，所以"什么时候算按下"由固件里的阈值决定，阈值可以逐键改、可以随方向改（按下与释放分开），Rapid Trigger 更是把"复位点"从固定值变成"上一帧位置减去一个偏移"。同一颗传感器，触发行为完全由固件定义——这就是磁轴键盘的核心：传感只负责给位移，语义全在固件。[80HE+ 产品页](https://wooting.io/zh-CN/wooting-80he-plus)

第四行的 8 kHz 是把模拟链路推到极限的做法：扫描、去抖、上报全都要跟上，否则 0.125 ms 只是纸面数。

## 在编码器链上的位置

它买霍尔器件、磁铁、轴体与 MCU，做键盘与固件，卖给玩家与开发者。上游是霍尔芯片厂与轴厂，下游是消费市场。这颗霍尔器件测的是 0~4 mm 的直线位移，与角度编码器不是同一个物理量，也不是同一个市场：磁轴键盘要的是低成本、单轴、免校准的线性霍尔，年用量以亿计；角度磁编要的是双轴、温漂可控、带校准与接口。

这条边界要说清：磁轴键盘的成功不能外推成"磁角度编码器的市场"；反过来，键盘上暴露的问题（零点漂移、按压姿态引起的横向偏移、长时间温升）与角度编码器面对的问题有重叠，但量级与验收方式不同。
