Voliro 做的是**能贴上去干活的飞行器**：官方规格表把 Voliro T 定义为 omnidirectional tri-copter，靠可倾转的旋翼改变推力方向，从而在任何姿态下把工具压到结构表面。倾转轴是这台机器上唯一"需要知道自己转到哪"的轴，也是全机最贴近关节编码器场景的地方——但官方规格表对此一字未提。

## 苏黎世起家，做接触式无损检测

法律主体是 Voliro AG，地址在 8005 Zurich，产品名 Voliro T。官网沿革页写得具体：起点是苏黎世联邦理工（ETH Zurich）的自主系统实验室（ASL），2019 年注册公司并获 Wyss Zurich 加速器支持，2022 年与 Shell、Petronas、Holcim 等早期用户做完现场验证后正式推出 Voliro T；CEO 与共同创办人是 Timo Müller，硕士论文期间做的第一台原型。业务是无损检测（NDT）：把测厚、电磁声、视觉等工具挂到飞行平台上，替人去做高处与受限空间的检测。行业目录列了油气、化工、风电、水泥与骨料、矿业、基础设施、电力与公用事业七类。[公司介绍](https://voliro.com/company/)

官网的卖点三条：稳定接触（可向结构施加最高 30 N 的力和数牛米扭矩）、360° 全向机动（可以朝任意方向倾斜并与任意朝向的表面交互）、自动化（有自动飞行模式与辅助自主，可在无 GPS 环境工作）。

## 官方规格表里能核对的数字

规格表是 PDF，页脚版本号 6.0，是这家公司公开信息里最实的一份。

| 公开项 | 官方口径 |
| --- | --- |
| 机型 | 多旋翼 / 全向三旋翼（omnidirectional tri-copter） |
| 重量（不含电池） | 3.7 kg |
| 最大起飞重量 / 最大载荷 | 6.0 kg / 1.0 kg |
| 尺寸 | 118×109×34 cm（整机装配状态） |
| 飞行时间 | 10–14 分钟（随任务与载荷） |
| 交互精度 | ±2 cm（标称环境、受训飞手） |
| 施加力 | 最高 30 N 稳定力与数牛米扭矩 |
| 感知 | 6 路 LiDAR 测距、6 路视觉测速、RTK GPS（多频，北斗/伽利略/格洛纳斯/GPS）、冗余 IMU + 气压计 + 磁力计、VGA 深度相机 |
| 环境 | −10…40 °C；自由飞行抗风 12 m/s，交互模式 8 m/s；禁雨雪与雾 |
| 载荷 | EMAT 与 UT 探头，测厚范围 2–150 mm，分辨率 0.06 mm |

两点值得单看：第一，它把"6 路 LiDAR + 6 路视觉测速 + RTK"写成标配，说明贴壁作业的姿态估计不靠单一传感器；第二，交互精度 ±2 cm 是"飞手在受训条件下"的口径，不是重复定位精度。[Voliro T 规格表 PDF](https://voliro.com/Voliro-T-Spec-sheet)

## 在编码器链上的位置

它买旋翼电机、倾转机构、测距与惯导模块，自己做飞控与接触控制，卖给检测服务商与资产方。倾转轴的数量官方没单列（"三旋翼"意味着三副旋翼，但是否每副都有独立倾转自由度、由几个舵机驱动，规格表不写）。倾转角如果靠舵机内部电位器或霍尔加高减速比推算，成本低但会漂；如果要绝对角度，就得在倾转轴上单独加一颗。这是这台机器上唯一值得谈编码器的位置，而它恰好落在"公开资料空白"里。

## 公开资料的边界

规格表没有公开：旋翼数量与倾转自由度、倾转执行器型号与反馈方式、飞控主频与控制周期、姿态估计的融合结构与输出频率、载荷接口协议、电池循环、价格。因此不能从"能施加 30 N 力"推出"倾转角一定闭环到某个精度"。本页不写这些。
