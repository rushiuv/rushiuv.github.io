极海是纳思达体系下的芯片公司，产品分两条来源：一条是打印机与耗材芯片，量大、对成本与一致性极敏感；一条是工业 MCU 与电机控制 SoC，APM32 通用系列与 G32 专用系列都在这里。G32R430 属于后者的新品类——它把"给编码器用"写进了型号定义：角度解算、多通道同步采样、编码器协议兼容打包成一颗芯片的卖点，这在国产 MCU 里是第一次明确落到料号上。

## 公司与股权

极海（Geehy）由纳思达股份有限公司（002180.SZ，2026 年公告拟将证券简称变更为"奔图科技"）通过极海微电子股份有限公司持股 81.084% 控制，旗下主体包括珠海极海半导体、极海半导体（深圳）、成都极海、杭州朔天等。[纳思达官网](https://www.ninestargroup.com/)；[子公司清单](https://www.qibook.com/company-wiki?name=奔图科技股份有限公司)

母公司主业是打印机与耗材：纳思达自述为全球第四大激光打印机厂商，主营激光打印机、集成电路芯片、通用耗材及核心部件三大板块。2025 年纳思达营收 165.15 亿元、同比下降 37.48%，归母净利润 -7.18 亿元；其中极海微电子营业收入 10.92 亿元、同比下降 21.99%，净利润 -0.66 亿元，芯片总销量 6.07 亿颗。**非打印耗材芯片业务营收 4.7 亿元、同比增长 5.41%**——工业与机器人这条线就长在这 4.7 亿里，占极海整体约四成。[纳思达 2025 年报报道](https://c.m.163.com/news/a/KQHRPIHJ05198CJN.html)

这个股权结构决定了两件事：现金流由打印机主业提供，芯片业务不用背短期盈利压力；客户资源一半来自打印耗材链条，工业侧的客户得自己一家一家打。

## G32R430 编码器专用 MCU

| 项目 | 公开参数 |
| --- | --- |
| 内核 | Arm Cortex-M52（Armv8.1-M），最高 128 MHz |
| 存储 | Flash 128 KB；ITCM 32 KB + DTCM 16 KB；4 KB Cache |
| 角度解算 | 内置硬件 TMU，支持自研 ATAN 电角度计算扩展指令；ATAN 精度优于 0.0001°，电角度输出延迟 < 1 µs |
| 模数转换 | 2 × 16 位 ADC（差分有效位 13.5 bit，可过采样提升）+ 1 × 12 位 ADC（最多 14 外部通道 + 2 内部通道） |
| 支持的编码器 | 官网口径：≥ 17 bit 磁编码器、≥ 23 bit 光编码器 |
| 模拟外设 | 2 × 10 位 DAC、4 × 可编程比较器、高精度温度传感器、主电电压检测（EVS） |
| 通信 | 2 × USART（最高 16 Msps，带 RS485 发送使能自动控制）、1 × I²C（400 kHz）、1 × SPI（最高 50 Mbit/s） |
| 协议兼容 | 多摩川、BiSS-C、SSI、SPI |
| 功耗 | Stop < 15 µA（唤醒 < 20 µs）；Standby < 2 µA（唤醒 < 50 µs）；官网称较传统编码器方案整体降耗约 50% |
| 电气与环境 | 1.7~3.6 V；-40~105 ℃；符合 IEC 61508；HBM ±4 kV、CDM ±1 kV |
| 封装 | UFBGA64 / QFN60 / QFN48 / QFN32 |

三个技术点值得展开。

**ATAN 硬件指令是这颗料的差异化所在。** 磁编码器解算要算 arctan(y/x)，通用 MCU 用 CORDIC 或查表，耗时在微秒到几十微秒；极海把这一步做成硬件指令，标称电角度延迟 < 1 µs、位置响应速度较传统方案提升约 40%。对高转速电机的换相环路，这个延迟直接变成相位滞后。

17 bit 对应 360°/131072 ≈ 0.0027° 的单步，实际精度仍取决于前端敏感元件与校准。

**这颗料没有 EtherCAT，也没有 CAN。** 通信资源就是两路 USART、一路 I²C、一路 SPI；EtherCAT 出现在极海另一条产品线上——G32R501 实时控制 MCU/DSP 做的 400 W 总线型高压伺服控制器参考方案。两颗料分工明确：G32R430 装在编码器里，G32R501 装在驱动器里。官方配套还给了 SDK、TinyBoard 开发板（搭载 G32R430CBU7，板载 RS-485 与 RS-422 接口、Geehy LINK 仿真器）与磁电式绝对编码器参考方案，另有基于 APM32E030、APM32F103 的编码器参考方案，那是给用通用 MCU 做编码器的客户准备的。

## 在编码器链上的位置

极海站在"编码器内部的主控"这个位置：敏感元件（霍尔或磁阻、光电二极管阵列、电感线圈）给出模拟量，G32R430 负责采样、解算、校准、编码与协议输出，最终交给伺服驱动器。竞争上，同台的有拿通用 Cortex-M4/M33 加定时器捕获做方案的各家 MCU 厂（包括兆易的 GD32 系列，那边走的是"通用 MCU + 多协议原生支持"的路子），极海的差异是把解算硬件化、把功耗压到 Stop 15 µA 这一档，代价是 Flash 只有 128 KB，做复杂补偿算法与多圈累加的余量有限。

这颗料的分档能力也被自己框住了：协议清单是多摩川、BiSS-C、SSI、SPI，没有 HIPERFACE DSL 与 EnDat；官方口径是"现已支持派样"，没有公布定点客户与量产项目。ATAN 指令是单周期还是多周期、0.0001° 在什么输入条件下测得，以及"支持 ≥23 bit 光编"对应的采样率门槛，都需要回手册确认。
