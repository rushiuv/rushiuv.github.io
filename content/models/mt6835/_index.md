## 核心参数

| 参数 | 数值与适用条件 |
| --- | --- |
| 角度分辨率 | 21 位，0～360° |
| 绝对值输出 | 四线 SPI、12 位 PWM |
| 增量 ABZ | 1～16,384 脉冲／圈，最高 65,536 步／圈 |
| 换向 UVW | 1～16 对极可编程 |
| 最高转速 | 120,000 rpm，见 Rev.1.3 适用条件 |
| 校准 | 客户端自动非线性校准，INL 典型 ±0.07°，按第 9 章条件 |
| 系统延时 | 匀速下典型 10 µs；BW=5 阶跃响应典型 100 µs |
| 温度／封装 | −40～125°C，TSSOP-16 |
| 理想数字码距 | 按21位全圈换算：360°/2^21 ≈ 0.00017166°；计算值，不是准确度保证 |
| 推荐供电 | 3.0～5.5 V；电气性能表默认4.5～5.5 V条件 |
| 工作电流 | 典型22 mA，最大28 mA；第6页电气表 |
| 工作磁场 | 30～1000 mT，芯片表面水平分量；按第9页单对极径向充磁条件 |
| 出厂INL | 25°C无偏心典型±0.5°；规定全温/装配条件最大±1.0° |
| 瞬态噪声 | 典型0.0015° RMS；25°C、ABZ模式、BW=5 |
| ABZ频率上限 | 第7页规定2.048 MHz；16384脉冲/圈时对应7500 rpm，不与120000rpm无条件同时取最大 |
| 推荐磁体示例 | 第9页Ø10mm、厚2.5mm单对极径向充磁磁体；气隙典型1mm、最大3mm，偏心最大0.3mm，需满足同页条件 |
| PWM频率 | 497或994 Hz，容差±8% |
| 非易失擦写 | 手册最低1000次；烧录供电与等待流程另按章节执行 |

资料定位：MT6835 Rev.1.3（2022-12）第5～9页、第9章；匀速自校准和EEPROM流程另见原厂自校准应用说明Rev.1.2。

## 工作方式与型号定位

MT6835使用AMR敏感结构与数字处理输出21位全圈角度，SPI、PWM、ABZ及UVW分别服务绝对位置、周期捕获、计数和换向。各输出的位宽与刷新条件应分别核对。

## 安装、接口与配置

客户端自动校准需要外部先提供稳定匀速，默认400～800rpm档需要64圈。校准期间不能用本颗尚未校准的角度输出维持所要求的独立匀速参考；其他速度档和圈数应按应用说明设置。

## 校准与选型验证

校准计算完成与EEPROM写入完成是两个状态。应用说明要求保存期间保持供电并等待规定时间，之后冷启动复核。匀速10µs延时与BW=5的100µs阶跃响应属于不同测试，不能从低匀速延时推导快速加减速误差。

Rev.1.3资料定位：Rev.1.3第1、3、6～7页分别给出产品特性、引脚和电气/输出参数；延时仍按匀速条件阅读。
