MA600是MPS的一颗TMR磁角度传感器。它把磁场方向变成数字角度，提供串行绝对位置、增量脉冲和电机换向输出。理解它的关键，是把分辨率、带宽和校准条件放在一起看。

截至2026年10月29日，MPS已将MA600标为**不推荐用于新设计（NRFND）**，同时说明继续为现有客户生产。新设计的官方后续选择是[MA600A](/models/ma600a/)，两者应分别核对手册，不能仅凭型号相近认定直接替换。[官方产品页](https://www.monolithicpower.com/en/ma600.html)

## 核心参数

| 参数 | 数值与适用条件 |
| --- | --- |
| 敏感技术 | 集成TMR；支持在轴及离轴安装 |
| 分辨率 | 12～15位，随滤波配置改变 |
| 动态配置 | 默认FW=5：12.5位、12 kHz；FW=12：15位、75 Hz |
| 串行数据 | SPI、SSI；输出字长16位，不等于16位有效分辨率 |
| INL | 25°C、45 mT时典型0.2°、最大0.6°；用户32点校准后，25°C时典型0.06°、最大0.1° |
| 磁场 | 最佳线性区20～80 mT；功能范围10～150 mT，两者不能混用 |
| 增量与换向 | ABZ每通道每圈1～4096脉冲；另有UVW |
| PWM | 12位；250 Hz或1 kHz标称输出频率 |
| 供电与电流 | 3.0～3.6 V，标称3.3 V；25°C静态电流典型7.5 mA |
| 温度与封装 | −40～125°C；QFN-16，3 × 3 mm |

依据[MA600原型号手册Rev.1.0](https://www.monolithicpower.com/en/documentview/productdocument/index/version/2/document_type/Datasheet/lang/en/sku/MA600GQ/document_id/10535/)，重点见第7、28页。数值保留测试条件，不把室温校准结果扩展为全温整机保证。

## 它测的是磁场方向，机械角需要靠安装关系建立

常见结构是在轴端固定一颗直径方向充磁的圆柱磁体，芯片放在磁体下方。磁体转动，芯片所在位置的磁场方向随之改变，器件输出一圈内的绝对角度。在这种单圈测量中，上电后读取位置不依赖先经过Z相标记。

MA600也支持侧轴安装。不过，芯片挪到磁体侧边以后，场方向与机械转角之间不再天然线性。手册提供BCT比例补偿，用于处理径向与切向磁场幅值不一致造成的误差；32点用户表再用于校正残余非线性。支持离轴，仍需要确定磁体、距离和补偿参数。

这些内容描述的是外部工作关系。仅凭TMR这一名称，不能反推出芯片内部采用哪种完整角度解算电路。

## 为什么15位和12 kHz不能直接写在一起

分辨率回答读数能分多细，带宽回答读数能跟上多快的变化。MA600通过滤波窗口在两者之间取舍，手册第28页给出了成组配置：

| FW配置 | 噪声口径分辨率 | −3 dB截止频率 | 恒速延迟补偿 |
| --- | --- | --- | --- |
| 0 | 12.3位 | 17 kHz | 关闭 |
| 5，默认 | 12.5位 | 12 kHz | 开启 |
| 8 | 14位 | 1.3 kHz | 开启 |
| 12 | 15位 | 75 Hz | 开启 |

因此，“15位、17 kHz”不能作为同一个工作点宣传。对位置保持和缓慢定位，可以讨论更窄滤波带来的读数稳定性；对快速运动，需要把传感器动态响应纳入控制环分析。

15位把一圈分为32768份，理想刻度约0.011°。这是按360°除以32768算出的刻度间隔。它不证明绝对误差也是0.011°，更不能替代INL测试。手册的分辨率还采用±3σ噪声区间口径，读取16位报文也不会自动获得16位有效精度。

## “No Latency”要放回恒速补偿条件里理解

原厂功能列表写有“No Latency”，配置表则明确写着恒速条件下的延迟消除。它表达的是相应滤波配置的补偿能力。启动、加速和反转时的动态表现，仍需按传递函数分析并验证。

SPI传输、主控调度和控制计算也各自占用时间。作为独立算例，6000 rpm等于每秒100圈；控制链多出10微秒，就对应0.36°机械转角。这个计算说明为什么系统时间预算需要单独做，并非MA600的实测延迟。

## 32点校准怎样把芯片指标变成系统结果

用户校准表给出了存储修正量的位置，外部参考系统负责提供真实角度。实际流程是先完成最终磁体和芯片装配，再对照参考角度测出误差，生成修正数据，写入并复查。

校准是否有价值，要看表格节点之间的残差、正反转差异、重复装配和温度变化。只在用于拟合的点上得到好结果，尚不足以证明整圈误差已经达标。

还要区分误差性质。稳定、可重复的角度偏差适合建立补偿表；随机噪声、轴承游隙和随负载改变的机械位移，不能只靠一张固定表解决。这是校准方法的工程边界，不是对MA600额外作出的性能承诺。

## 接口怎样接到控制系统

SPI既能读角度，也能做寄存器配置；SSI用于角度读取。ABZ便于连接增量计数器，UVW服务于换向需求，PWM用脉宽传递绝对位置。使用时还应核对引脚复用，接口名称齐全不代表所有功能都能同时引出。

ABZ每通道4096脉冲，在主控四倍频计数时对应每圈16384个边沿计数。脉冲数、边沿数和绝对角度分辨率是三种不同口径。

芯片还提供通电期间的多圈计数。手册第35页说明，测得圈数及多圈偏置在启动时清零，偏置不能存入NVM。因此，有多圈输出功能不能推导出断电转动后仍能恢复绝对圈数。

## 用它做设计，先锁定哪几个条件

评估MA600时，先确定安装几何、工作磁场、所需带宽和接口，再讨论校准后的误差目标。尤其要把20～80 mT最佳线性区与更宽的功能范围分开，不能把“还能输出角度”当作“仍满足同一精度”。

对于已有MA600产品，重点是保留原型号的配置、标定和验证依据。对于新设计，按官网指引评估MA600A，并重新检查供电、引脚、时序、寄存器和校准流程。
