Nautica Technologies

苏黎世海事机器人公司，HYDRA 是常驻船上自主爬行清刷船体的 rAFS 系统，专利待审，CTO 出身为 ETH 无人机研究者。

词条更新 2026.10.22 · 0 篇相关文章

官方网站 ↗

Nautica Technologies 做的是海事整机应用：一台常驻在船上的机器人，在船不起坞、不停租的情况下持续爬行清刷船底，用机械方式替代毒性防污漆。它不是编码器相关公司，但对角度传感有一个明确的抬升作用——船体表面爬行要自主化，轮子上那几路原来只当换相用的反馈，就得变成导航件。

苏黎世起家，ETH 与 EPFL 背景

官网自述是瑞士初创，团队根在苏黎世联邦理工（ETH Zürich）与洛桑联邦理工（EPFL），法律主体写为 Nautica Technologies AG。公开的管理层两人：CEO 是 Cédric Portmann，CTO 是 Mina Kamel。产品名 HYDRA，定位为 autonomous robotic antifouling system，缩写 rAFS，官网注明专利待审（patent pending）。HYDRA 与公司介绍

商业模式写得很清楚：不做一次性服务，而是把整台装置装到船上，按船东的航线节奏定期跑，每次跑完出一份可审计的船体状态报告，给船东、租家与船级社看。这条"每次运行都有报告"的闭环，是它和传统水下清刷服务的分界。

公开的产品口径与它替代的东西

公开项官方口径备注
系统形态常驻船上的自主爬行机器人系统官网 How It Works
作业节奏按航线与靠港规律定期跑，安装、运行、核验三步官网
安装方式随船安装，不需进干船坞官网称 no retrofit downtime
输出物每次运行生成船体状态报告给船东、租家、船级社
官方宣称的收益最高可挽回 20% 燃油（按船建模，非实测承诺）官网 modeled per vessel
合规指向CII、FuelEU Maritime、EU ETS官网
团队来源ETH Zürich 与 EPFL官网

表里"20%“必须按官方口径读：官网自己在旁边标了 modelled per vessel，是按单船模型算出来的数，不是第三方实测。把它当结论引用就错了。

它替代的是防污漆的化学路线——官网的论证是常规涂料靠向海水释放杀生物剂工作，且从第一天起就在衰减；HYDRA 的思路是不让附着开始。这套论证是它自己的，本页不当成行业共识。

在编码器链上的位置

它买电机、驱动、传感与密封件，做整机与船队服务，卖给船东与航运运营方。可动件集中在两处：贴着船体走的驱动轮（或驱动脚）与刷辊。这两处本来只需要换相级的反馈，一旦要做自主路径与覆盖率的核验，轮上的角度就变成里程与位姿的输入，对分辨率、温漂与长期一致性的要求整体抬一档。

但公开资料到此为止：官网没有给驱动方式、轮数、刷辊数量、吸附方式、通信接口。它值多少颗编码器，只能靠现场或拆机确认，不能从宣传页推。

官网是 GitHub Pages 单页站，除首页无独立公司页或技术页；唯一外部入口是 LinkedIn。
