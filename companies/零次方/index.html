零次方

合肥零次方机器人（ZERITH）：ZERITH H1 系列轮臂人形本体加 Zerith Data 数据基础设施，方案落在即时零售无人仓、机器人小店与教育科研。

词条更新 2026.10.22 · 0 篇相关文章

官方网站 ↗

零次方把产品定义成两半：一半是本体（ZERITH H1 系列轮臂人形），一半是数据（Zerith Data，遥操采集加标注加资产管理）。这个组合对做位置反馈的人有直接含义——本体侧要关节角度，采集侧要人手的位姿，两条线都要编码器，但精度与成本口径不同：一个按整机可靠性算，一个按数据质量算。

合肥主体与两件核心产品

官网主体是合肥零次方机器人有限公司，备案 皖ICP备 2026024715 号-1，公网安备 34011102004288 号，全国咨询热线 400-169-7658；公开报道里的创始人与 CEO 为闵宇恒。官网把 ZERITH H1 系列写成"面向真实世界操作的具身智能通用本体平台"，形态是轮臂人形；Zerith Data 写成"面向具身智能训练的数据基础设施"，集成任务协同、遥操采集、智能化标注与数据资产管理，做成采集、使用、管理的闭环。解决方案四项：即时零售无人仓、机器人小店、数据采集中心、教育科研。

在编码器链上的位置

本体侧：轮臂形态意味着底盘是轮式、上身是臂，轮端要测速与里程、臂关节要绝对角度，与双足人形相比少了平衡对带宽的苛刻要求，多了对长时运行的稳定要求。采集侧：遥操作要同时记录操作者的手部位姿与机器人关节角，两路都要可对齐、可复现，这对编码器的绝对性与时间戳一致性提出要求。公开材料两边都只到功能层，没有关节数、编码器类型与位数。能推的是它把数据当产品，因此对"角度数据的可重复性"可能比对"单点精度"更敏感；不能推的是具体器件选择。

ZERITH H1 的自由度、单臂负载、重复定位精度、关节模组来源均未公开；Zerith Data 的采集通道数、标注吞吐也未公开。
