矽睿

矽睿（QST）：2012 年上海 MEMS 与磁传感平台，AMR 磁力计 QMC6308 给 1°~2° 航向精度，无编码器级角度型号。

词条更新 2026.10.22 · 1 篇相关文章

官方网站 ↗

矽睿不站在编码器整机那一层。它的位置是"AMR 磁敏元件 + MEMS 惯性"的芯片平台：对外卖的是磁力计、六轴 IMU、加速度计和汽车底盘传感器。对做编码器的人，它的价值在于磁敏元件与校准算法的底座，以及汽车前装那条线的工艺纪律；但它的公开产品里没有编码器级磁角度型号，这一点必须在页面最前面说清，否则很容易把"磁力计的 1°~2° 航向精度"当成角度编码器的精度。

公司与品牌

上海矽睿科技股份有限公司（QST），官网自述 2012 年成立，定位以应用为导向的多传感器平台。产品包括六轴 IMU、加速度计、环境传感器、组合传感器，磁性传感器芯片（磁力计），以及汽车与物联网智能模组和系统。应用市场聚焦智能手机、智能穿戴、物联网、智能制造与汽车电子，官网称正"向智慧医疗、低空经济与人形机器人市场演进"。

体系认证是这家公司比较硬的一块：ISO 26262 功能安全管理体系 ASIL D 等级、IATF 16949、ISO 27001；磁力计 QMC5883P 通过 AEC-Q100。荣誉方面，六轴 IMU QMI8658 获 2022 与 2023 年"中国芯"奖，2025 年获工信部专精特新"小巨人"。汽车底盘业务由"驭芯（上海 / 江苏 / 浙江）“承担。公司简介与资质

角度与磁相关产品线的公开规格

严格说，下表里没有一行是编码器产品：磁力计测的是磁场方向（罗盘航向），IMU 测的是姿态，底盘传感器测的是轮速与车身高度。列在这里是为了看清这条路线的物理边界——航向精度 1°~2° 与编码器的角秒级要求差三个数量级。

系列 类型 公开指标 其他公开参数
QMC6308 单芯片 AMR 磁力计 16 位 ADC、2 毫高斯磁场分辨力、1°~2° 定向精度 WLCSP 0.8×0.8×0.5 mm、最高 1500 Hz 数据率、I2C、−40~85 °C、内置温度补偿
QMC5883P 三轴地磁传感器（AMR） 16 位 ADC、1°~2° 罗经航向精度 LGA 3×3×0.9 mm、1500 Hz、I2C、通过 AEC-Q100
QMC6309 / QMC6309H / QMC5883L 地磁系列 未在类目页列位数 消费与移动设备分档
QMI8658 / QMI8610 / QMI8A01 / QMI8A01z 六轴 IMU（三轴加速度 + 三轴陀螺） 类目页未列零偏与噪声指标 QMI8A01 带运动协处理器，QMI8A01z 符合 AEC-Q100
底盘传感（驭芯） 轮速、车身高度、偏航率、加速度、转速/位移 未公开逐型号指标 带接插件 / 轮毂轴承 / 集成 EPB 等安装形态

值得记的一点：QMC6308 与 QMC5883P 都是 AMR 加 16 位 ADC 的架构，软件侧随芯片提供指南针航向角、硬磁与软磁校准库。这套"磁阻桥 + ADC + 校准算法"的结构，与磁角度编码器是同源的——差别在下游：罗盘要的是磁场方向，编码器要的是磁铁相对芯片的角度，且必须跨装配公差稳定。磁力计目录

在编码器链上的位置

矽睿卖敏感元件与算法，属于这条链的上游一格：磁阻桥、ASIC、校准库自己做，客户是手机与可穿戴、汽车 Tier1 与模组厂。要判断它会不会进入关节编码器，公开线索只有两条——AMR 磁力计这条技术底座，和汽车底盘位置/转速传感器这条客户渠道；两条都不足以推出"已有编码器级角度产品”。

不能推断的：它是否在为编码器做在研型号（官网无此类页面）；也不能把它的车规资质当成关节编码器的准入证明——那是体系，不是产品。
