01 / HALL / AMR / TMR

磁场与磁编码

同样输出角度，为什么换芯片后，磁铁也得重新看？

从感应分量、磁体布置到后端角度计算，把“接口能接上”和“测量条件成立”分开。先确定在轴还是离轴，再比较器件。

建议这样读

  1. 偏心量怎样换成角误差

    定义读数半径和图案轴，再算适用结构下的误差。

    ↗

  2. 对径磁场：坐标变了，物理量变了吗

    区分全局场矢量、局部坐标和器件敏感分量。

    ↗

02 / COIL / TARGET

电感、线圈与靶体

信号幅度变大了，角度误差为什么不一定变小？

电感反馈不是一颗芯片的独角戏。线圈、靶体、气隙与解调链共同决定信号，把材料替换和动态性能放在同一条链里看。

建议这样读

  1. 芯片INL与机械角误差如何分层

    先确认被测量，避免把通道线性度当整机角精度。

    ↗

  2. 输入频率、刷新率与帧速率各管什么

    把周期数、转速和输出事件放回同一条时序。

05 / INL / NOISE / DRIFT

误差、校准与温度

室温一圈校准好了，换温度、转速和寿命条件还算数吗？

先分清周期误差、零位漂移、噪声和动态滞后。校准表解决的是指定条件下的一部分误差，不是所有工况的统一答案。

建议这样读

  1. 自校准修什么，依靠什么条件

    按修正对象、参考来源和运动要求比较。

    ↗

  2. 验证参考也要独立

    同一运动假设下自洽，不代表已恢复真实角度。

    ↗

继续算与测

  • RMS变小了，噪声就变小了吗？ →
  • 把李萨如椭圆变圆，为什么角度还会错？ →
  • 校准和验收都拿匀速当真值，会发生什么？ →
  • 温补前先回到同一温度，看看零位还在不在 →

阅读时带着这个检查项比较校准前后时，固定温度、磁路、速度和滤波配置。

补基础

INL：位数之外的整圈角度偏差自校准：先问它在修正哪种误差

06 / MOTOR / LOAD / TORQUE

双编码器与关节反馈

两个角度的差值，在说扭矩、温漂，还是采样不同步？

从电机端与负载端的位置关系入手，再讨论减速比、机械弹性和同步。多一路观测带来了新信息，也带来了需要解释的不一致。

建议这样读

  1. 角差估扭矩，先算同步误差

    以明确设定的刚度重算量化与时间预算。

    ↗

  2. 同尺度双读头能压掉哪一阶

    用空间阶次响应区分读头平均与电机/负载两端反馈。

    ↗

继续算与测

  • 两路角差估扭矩，先算同步误差值多少钱 →
  • 两个读头平均，先问要消哪一阶 →
  • 用KIN52示例，把参数表改成整机验收记录 →
  • 免电池多圈记住了圈数，为什么接口仍要供电？ →

阅读时带着这个检查项先统一角度与时间基准，再判断差值；双编码器不自动等于扭矩传感器。
