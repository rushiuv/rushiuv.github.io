01 / HALL / AMR / TMR

磁场与磁编码

同样输出角度，为什么换芯片后，磁铁也得重新看？

从感应分量、磁体布置到后端角度计算，把“接口能接上”和“测量条件成立”分开。先确定在轴还是离轴，再比较器件。

建议这样读

  1. 替代一颗芯片，为什么要重看磁路？

    沿Hall与TMR的感应差异，回到磁体和安装条件。

    ↗

  2. 滤波开大一点，会丢掉什么？

    从AS5600与KTH78的比较，区分角度平稳和动态响应。

    ↗

阅读时带着这个检查项先查磁场方向与强度，再看气隙、偏心和校准配置。

补基础

磁编码器：霍尔、AMR与TMR怎样读角度在轴、离轴、气隙与偏心：先把几何关系说清

02 / COIL / TARGET

电感、线圈与靶体

信号幅度变大了，角度误差为什么不一定变小？

电感反馈不是一颗芯片的独角戏。线圈、靶体、气隙与解调链共同决定信号，把材料替换和动态性能放在同一条链里看。

建议这样读

  1. 铝靶换成铜靶：先追哪条误差链？

    用材料变化这个具体问题，阅读信号形成与角度解算。

    ↗

  2. 电感测角的动态时间花在哪里？

    把激励、感应和处理链拆开，不只比较输出更新率。

    ↗

阅读时带着这个检查项把幅值、相位、谐波和转速条件一起记录，不只看波形高度。

补基础

电感编码器：线圈和金属靶怎样测位置气隙：先找测量基准，再看磁场工作窗口

04 / BiSS / SSI / SPI

接口、帧与采样时刻

波形已经有了，为什么控制器还是不认这个角度？

把电气层、帧格式、状态位和数据对应的采样时刻分开检查。名字一样的接口，也不能省掉具体版本与主从配置核对。

建议这样读

  1. 按BiSS接好了，为什么仍然不通？

    从接入问题回到设备实际发送的帧，而非只认协议名称。

    ↗

  2. 接口除了传一个数，还承担什么？

    继续看诊断、故障追溯与系统接口生态。

    ↗

阅读时带着这个检查项先留完整原始帧与时钟，再核对长度、位序、CRC和超时。

05 / INL / NOISE / DRIFT

误差、校准与温度

室温一圈校准好了，换温度、转速和寿命条件还算数吗？

先分清周期误差、零位漂移、噪声和动态滞后。校准表解决的是指定条件下的一部分误差，不是所有工况的统一答案。

建议这样读

  1. 校准点越加越多，为什么温漂仍在？

    围绕校准维度阅读，不把插值点数当全温性能。

    ↗

  2. 出厂校准为什么也会“过期”？

    继续追问温度回程、装配变化和长期漂移。

    ↗

阅读时带着这个检查项比较校准前后时，固定温度、磁路、速度和滤波配置。

补基础

INL：位数之外的整圈角度偏差自校准：先问它在修正哪种误差

从电机端与负载端的位置关系入手，再讨论减速比、机械弹性和同步。多一路观测带来了新信息，也带来了需要解释的不一致。

建议这样读

  1. 从两个角度，到关节扭矩的距离

    先看双编码器的系统位置，再审查差值成立的条件。

    ↗

  2. 两颗都合格，为什么读数还能不一致？

    把单颗误差、安装与温度放进差值预算。

    ↗

阅读时带着这个检查项先统一角度与时间基准，再判断差值；双编码器不自动等于扭矩传感器。
