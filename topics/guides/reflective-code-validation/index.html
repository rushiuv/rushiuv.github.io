反射绝对码读错，不能只看正余弦有多圆

亮暗判决与周期细分是两条测量任务，用电流区间检查阈值是否还存在。

光学编码器的周期信号很平滑，仍可能在某个位置突然跳过一段角度。若绝对码身份读错，后端把周期内位置细分得再漂亮，也只是在错误区间里给出细刻度。

先问亮暗电流还有没有间隔

对一个二值码位，设暗位电流落在 [I0L,I0H][I_{0L},I_{0H}]，亮位落在 [I1L,I1H][I_{1L},I_{1H}]。要用单一阈值 TT 保证区分，至少要求：

I0H<T<I1L I_{0H}<T<I_{1L}

自设暗位2～4 µA、亮位9～11 µA，阈值取6.5 µA，两边最小余量都是2.5 µA。若污损把亮位最低值压到5 µA，暗位上限仍为4 µA，改用4.5 µA才只剩0.5 µA余量。

若邻位串光又让暗位最高到6 µA，而亮位最低仍为5 µA，两区间重叠，就没有一个阈值能保证分开。此时继续调阈值只能交换两类错误，不能恢复已经丢失的对比。

绝对身份与细位置分别验收

令机械位置为归一化角u。绝对码回答u属于哪一段，周期信号回答该段内的细位置。前者的错误可能跨段，后者的非线性通常表现为周期内偏差；二者不能只汇成一个静止噪声数字。

公开的反射式M码专利通过反射面与受光组配置讨论接光和码字读取。这里的“错位接光”，与把周期谐波正负贡献积分相消，解决的是不同问题；看到两组探测器不能直接推定它们在消某一阶谐波。

扫阈值，同时保存原始码位

固定一套几何，扫描气隙、倾角、光斑位置与可控遮污。记录每个码位亮暗电流分布，逐阈值统计假亮、假暗和最终错段位置，再独立检查周期细分误差。

温度与速度改变后，要重新看分布是否重叠。只记录总受光电流或最终角度，会漏掉临界码位；只展示一次无错码运行，也不能证明整个安装窗口都存在足够判决余量。

最差码位通常比平均光量更重要。若只有一个码位的暗电流上限抬高，平均值仍能很好看，错误却会集中在少数绝对位置。验收记录应保留码位编号与机械位置的对应，让局部污点、邻位串扰和整体光量变化能够分开追踪。
